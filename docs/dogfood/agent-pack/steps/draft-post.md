# Assignment: Draft a post

Draft one page or post that answers one search intent the task names, or the one
you judge most worth answering if it names none.

Put the draft where the repository keeps its content, in the format the rest of it
uses. Do not publish anything and do not change navigation; a human decides what
goes live.

End with the handoff your persona describes.
