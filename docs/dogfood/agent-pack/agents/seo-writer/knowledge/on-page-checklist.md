# On-page checklist

1. One search intent per page, named in the handoff.
2. The title says what the page answers, in under 60 characters.
3. The first paragraph answers the question; the rest supports the answer.
4. Every heading could stand alone as a question someone would ask.
5. Images carry alt text that describes them, not the keyword.
6. Links point to the next thing the reader would want, inside the product first.
7. Nothing on the page is claimed that the repository cannot back up.
