**Run #3 — the real verdict.** Every functional criterion passed: QA wrote 6 Vitest unit tests and 10
Playwright e2e tests (10/10). Review and QA both failed the feature on one documentation defect — the
README claims *"Node.js 18+"* while the installed Vite 7.3.6 requires `^20.19.0 || >=22.12.0`, and
`package.json` has no `engines`. There is no route from that finding back to the Developer inside the
run (`TASK-183`).

**Run #3's closeout** failed first with Cursor exit `3221225794` (`0xC0000142`): the agent shell's
30-minute limit had killed the server's wrapper, and the orphaned server could no longer spawn CLIs —
a setup artefact (§12). Restarted after the server was relaunched, it failed again for a real reason:
the Orchestrator persona answered with an `isotopy-orchestrator-decision` block instead of a closeout
record (`TASK-184`; the same in runs #4 and #5).

**Runs #4 and #5 — the loop that could not converge.** The Orchestrator correctly started a narrow fix:
*"set README to ^20.19.0 || >=22.12.0 … add the same range to package.json engines … do not change game
or score behavior"*. All three runs' `implementation` stage carried the same Cursor session
`2aa7153f-d094-44c2-bec1-92fc7e4307e2`; the resumed Developer answered *"Taking stock of what's already
on disk … Nothing left to implement"* and passed, and the README never changed (`TASK-180`).

**The stall.** After run #5 the Orchestrator proposed a new team whose roles used `persona` instead of
`id`/`skill`; the schema rejected it, `decisionError` recorded it, and the initiative stayed `running`
with nothing in flight (`TASK-182`). The *three blocked runs* rule never applied.

## 8. Embedded Preview checks

`Start the product` with `npm.cmd run dev` **failed** with `MODULE_NOT_FOUND` — and this time from a
server launched in a clean PowerShell window, so not the launch method. Replicating Isotopy's spawn
(`cmd.exe /d /s /c ""npm.cmd" "run" "dev""`) gave the real error: *Cannot find module
`C:\Development\smekai\dogfood-arcade-cursor\node_modules\npm\bin\npm-cli.js`* — under a quoted bare
name, `cmd` resolves the batch file's `%~dp0` against the working directory. With
`C:\Program Files\nodejs\npm.cmd` as the executable the product reached **ready** and served the shell
on 5191 (`TASK-181`). No games to play.
