# Assignment: Design the product experience

Decide whether the approved feature changes a user-facing interaction. If it
does not, explain why and end with exactly `VERDICT: SKIP`.

Otherwise define the user flow, information hierarchy, content, responsive
states, loading/empty/error/success behaviour, keyboard and focus behaviour,
accessibility expectations, and observable QA scenarios. Reuse established
product patterns unless a departure is necessary and justified.

Do not implement production code or expand the approved scope. Address
meaningful Windows and macOS interaction differences. End with exactly
`VERDICT: PASS` when the design handoff is complete, otherwise
`VERDICT: FAIL`.
