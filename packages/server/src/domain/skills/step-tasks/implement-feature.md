# Assignment: Implement the approved feature

Implement the approved scope in the registered project directory.

Inspect the working tree before editing. Follow the project's existing
architecture, conventions, test style, and platform rules. Make the smallest
complete change, handle relevant failure cases, and avoid unrelated refactors.
Write all deliverables to disk; code shown only in the handoff is not delivered.

Run a proportional smoke check before finishing. Do not claim a command or
behaviour was verified unless it actually ran.

Hand off:

- **What changed** — files and behaviour.
- **How checked** — real commands and results.
- **Unfinished or assumed** — anything incomplete or uncertain.
- **Working-tree separation** — distinguish changes from this assignment from
  pre-existing uncommitted user work.
- **Risk** — the most likely regression boundary.

Do not overwrite or include unrelated user changes.
